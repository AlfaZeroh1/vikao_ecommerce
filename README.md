# Vikao Marketplace: MVP (vikao.io)

Buy, rent and lease homes, land and commercial space, book short stays, hire property services, and reserve **Official Vikao** listings with M-Pesa.
Stack: PHP 8.1+, MySQL 8 / MariaDB 10.6+, jQuery, Tailwind (CDN), Font Awesome, SweetAlert2, Swiper, Quill, SortableJS.

## Quick start (XAMPP / Laragon / LAMP)
1. Copy the `vikao/` folder into your web root, for example `htdocs/vikao`.
2. `cp config/config.sample.php config/config.php`, then set your DB credentials and `app.url`.
3. Install the database and demo data:
   ```bash
   php database/install.php --fresh      # schema + Kenya locations + taxonomy + demo data
   php database/install.php --fresh --no-demo   # clean production install
   ```
   (Or import `database/schema.sql` then `database/seed.sql` in phpMyAdmin. Demo data needs the CLI.)
4. Make `uploads/listings/` writable by the web server, then open `http://localhost/vikao`.

## End-to-end pipelines
**Normal ad:** Sell → status `pending` → PMS *Ad review* approves or declines → user is notified (in-app + email) → ad goes live. Every edit or re-open goes back to `pending`.
On the ad page, buyers can **start a chat** (one conversation per ad per buyer) or **show the phone number** (each reveal is counted).

**Official ad:** PMS *Official store* publishes it instantly with a reservation fee and packages → buyer taps **Reserve now** → order page (choose a package, enter contact details) → order number is generated → checkout → M-Pesa STK push (simulated phone with PIN) → payment success → order `paid` → summary email (in `email_outbox`) → notification → PMS alert (in `pms_events`) → "Order placed" page.

## Database highlights
- **Geography:** `countries` (18 East and Central African countries, only KE active) and a `locations` tree (county → sub-county → area). It ships with all 47 counties, every constituency/sub-county, and about 300 popular estates. Labels per level are set per country.
- **Identity:** `users` (normal or official, user/staff/admin roles, password optional), `user_oauth_accounts` (Google/Apple/Facebook ready), `user_tokens` (remember-me, API/Flutter, reset, OTP), `badges` and `user_badges`, `membership_tiers`.
- **Listings:** the core `listings` table plus typed detail tables (`listing_residential_details`, `_commercial_`, `_land_`, `_service_`). This keeps every filter indexable without slow EAV lookups. Also `features`, `listing_features`, `listing_media`, `listing_packages`, `listing_service_areas`, `listing_reviews` (moderation audit), `listing_reports` and `listing_stats_daily`.
- **Commerce:** `orders` (with listing and package snapshots), `order_status_history`, `payment_methods`, `payments` (Daraja STK fields are already there).
- **Messaging:** `conversations` (unique per listing and buyer) and `messages`.
- **Integration:** `notifications`, `email_outbox`, `pms_events` (transactional outbox for the real PMS), `activity_log`, `rate_limits`.
- Normalised `size_sqm` / `size_acres` columns make size filters work across units.

## Going to production
- Set `payments.mpesa.simulate = false` and call Daraja inside `start_payment()` (`includes/services/orders.php`). The callback endpoint is already at `api/payments.php?action=callback`.
- Set `mail.driver` to `mail`, or swap in PHPMailer/SMTP inside `queue_email()`.
- Replace the Tailwind Play CDN with a compiled build: use the same theme as `tailwind.config` in `includes/layout/header.php`.
- OAuth: verify the provider token, then call `auth_login_oauth()` (`includes/auth.php`).
- If your MySQL build lacks FULLTEXT, install with `--no-fulltext` and set `search.driver = 'like'`.
